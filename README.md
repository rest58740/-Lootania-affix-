# 路塔尼亞 Lootania 詞綴表 非官方

MapleStory Worlds「路塔尼亞 Lootania」的**秘藏能力（前綴／後綴）詞綴表**。
官方沒有公布詞綴的數值範圍，這裡整理玩家擷取到的裝備資料，列出每條詞綴 **T10～T1 的數值範圍**，打裝時可以直接查。

## 可以查什麼

- 這條詞綴是第幾階（T10 最差、T1 最好）
- 每個 T 級的數值範圍
- 哪些裝備分類會出現哪些詞綴（戒指、弓弩、帽子…分開顯示）
- 傳奇裝備的固定能力範圍

## 怎麼使用

1. 到右邊的 **Releases** 下載 `詞綴表.exe`。
2. 雙擊開啟（不用安裝 Python）。
   第一次開啟如果跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
3. 左邊選裝備分類，右邊就是那個分類的詞綴和 T1～T10 範圍。
   - 上方可以篩選前綴／後綴／傳奇、搜尋詞綴名稱
   - 雙擊一列可以看所有紀錄（裝備、裝備等級）
   - 右上角可以切換日光／黑夜模式、匯出 CSV（Excel）

## 自動更新

詞綴表 exe 開啟時，會到這個專案下載最新的 `affix_db.json`，有新資料就自動更新（也可以按「檢查更新」）。
**不用重新下載 exe**，資料更新後大家下次開啟就會看到。

- 只會連到 `raw.githubusercontent.com` 下載這個專案的 `affix_db.json`，不會上傳任何東西。
- 沒有網路也能用，會顯示上次下載的資料。
- 下載的資料存在 `%LOCALAPPDATA%\Lootania詞綴表\`。

## 一起補齊詞綴表

裝備越多，表越完整！歡迎分享裝備截圖（每件裝備 2 張）：

1. 滑鼠停在裝備上，**按住 Tab** 截圖：會顯示 [前]／[後]、T 級和數值範圍
2. **放開 Tab** 再截一張：會顯示實際骰到的數值

說明框要完整入鏡（從裝備名稱到最後一條詞綴），T1～T3 的高階詞綴特別稀有，非常歡迎！
也可以用 [裝備截圖工具](https://github.com/rest58740/-Lootania-) 一鍵截圖。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `affix_db.json` | 詞綴資料（詞綴表 exe 會從這裡自動更新） |

`affix_db.json` 每一筆是一條詞綴紀錄：

| 欄位 | 說明 |
|---|---|
| `item` | 裝備名稱 |
| `category` | 裝備分類（戒指、弓弩…） |
| `part` | 部位 |
| `ilvl` | 裝備等級 |
| `kind` | `前`＝前綴、`後`＝後綴、空白＝特殊 |
| `tier` | T 級（1～10，0＝沒有 T 級） |
| `rarity` | `傳奇`＝傳奇裝備的固定能力 |
| `parts` | 詞綴內容：`name` 名稱、`lo`～`hi` 範圍、`value` 實際數值、`pct` 是否為 % |

資料來自玩家擷取的遊戲畫面（遊戲版本 v0.7.7 起），數值範圍會隨著收集到的裝備越來越完整。
